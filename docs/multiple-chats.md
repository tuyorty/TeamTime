# Несколько отделов на одной борде xTime

Один экземпляр бота принимает расписания и дейлики из нескольких разрешённых бесед.
На сайте используется общий справочник сотрудников. Номер темы и номер сообщения
определяются вместе с ID беседы: одинаковые номера в двух отделах не конфликтуют.

## Подключение лаборатории

1. Добавить того же бота в беседу лаборатории. Для получения обычных сообщений
   назначить его администратором либо отключить Privacy Mode через BotFather.
   После изменения Privacy Mode Telegram рекомендует повторно добавить бота в группу.
   Для реакций и удаления служебных ответов нужны соответствующие права группы.
2. Администратору беседы отправить `/bind расписание` в теме с расписаниями
   («виклики», «Виклики. Расписание» или любое другое название) и `/bind дейлики`
   в теме с дейликами. Название темы само по себе не настраивает приём живых сообщений.
   Для расписания также принимаются `/bind виклики` и `/bind weekly`.
3. В xTime открыть **Админка → Telegram → Чаты** и разрешить новую беседу.
   До разрешения бот не принимает её сообщения. Альтернатива: добавить привязки
   chat_id/thread_id через админку; это одновременно разрешает беседу.
4. В **Админка → Сотрудники** добавить недостающих людей с их «Фамилия И.О.».
   Заполнять нормы и условия оплаты по реальным данным компании.
5. В **Админка → Telegram** связать появившиеся аккаунты с сотрудниками.
   Расписание сопоставляется по ФИО в тексте, дейлик — по Telegram ID отправителя.
   Ник вроде `Rinat Sharik` не заменяет явную привязку аккаунта к «Шарапов Р.Р.».
   После привязки ранее принятые несопоставленные сообщения переразбираются.
6. Отправить тестовое расписание и дейлик от сотрудника, проверить реакцию бота,
   **Инбокс** и общий экран `/tv`. Второй экземпляр бота с тем же токеном не нужен.

После добавления бот обрабатывает поступающие сообщения. Для прежних расписаний
и дейликов использовать **Админка → Импорт истории**: экспорт беседы из Telegram Desktop
в JSON, с тем же ID чата. Повторный импорт не создаёт дубли.

## Форматы лаборатории

Поддерживаются `#дейлик` в начале сообщения, дата рабочего дня отдельно от даты отправки,
эффективность с двоеточием и без него, комментарий в скобках после процентов,
окончание `24:00`, длинные тире и прочерки выходного. Скопированные жирные заголовки
дней вида `**ПН: 15:30 - 20:30**` тоже читаются.

```text
#расписание
Спринт 02.11 - 08.11
Иванов И.И.
ПН — ВС: отпуск
```

Диапазон распространяется на все семь дней. «Отпуск», «больничный» и «отгул»
в заметке расписания отображаются как отсутствие; явно заданный ручной статус
имеет приоритет. Эти отметки следуют за версией расписания и не создают ручных статусов.

Интервалов может быть больше двух, например:

```text
10:00 - 12:00; 13:00 - 17:00; 20:00 - 23:00
```

Это 9 часов: перерывы между интервалами в часы не входят. Правило одинаково
для плана и дейлика. Один интервал `9:15 - 18:10` означает весь указанный промежуток;
комментарий про обед после эффективности не задаёт отдельный перерыв.

Документация Telegram: [Privacy Mode](https://core.telegram.org/bots/features#privacy-mode),
[получение сообщений ботами](https://core.telegram.org/bots/faq#what-messages-will-my-bot-get).
