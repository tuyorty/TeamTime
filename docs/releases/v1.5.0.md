# xTime v1.5.0

## Изменения после v1.4.1

- Добавлен отдельный экран **`/tv`** для офисного телевизора, доступный по ссылке **«Экран ТВ»** в разделе «Сегодня». Оформление, полосы расписания, шрифты и темы соответствуют основному приложению.
- Показаны все сотрудники: офис, удалёнка, начало позже, завершение по плану, выходной, отсутствие или неизвестное рабочее время. Сумма категорий равна размеру команды.
- У каждого сотрудника видны фотография, статус, интервалы и место работы. Справа — ближайшие начала и окончания работы и сводка на завтра.
- Часы в правом верхнем углу идут с секундами; их размер уменьшен, чтобы они не перетягивали внимание с расписания.
- На экране нет бокового меню, кнопок управления, контактов, финансов, дейликов и текста задач. Если команда не помещается, страницы сменяются каждые 15 секунд: до девяти сотрудников в Full HD и до шести в HD.
- Расписание обновляется автоматически. При сбое связи остаются последние данные с отметкой об их свежести; после восстановления соединения экран продолжает работу сам.

Экран показывает **план**, а не подтверждённое присутствие. Отдельный учёт перерывов и продолжения вчерашней ночной смены по-прежнему отложен. Подробнее: [экран для телевизора](../tv-screen.md).

## Файлы обновления

- `xtime-v1.5.0.tar.gz` — автономный архив с образами приложения и PostgreSQL для **Linux amd64**.
- `xtime-v1.5.0.tar.gz.sha256` — контрольная сумма.
- В архиве: `images.tar.gz`, установщик, серверный Compose, шаблон настроек, `VERSION`, `README.md` и эта инструкция под именем `UPDATE.md`.

Рабочий `.env` и данные сотрудников в архив не входят. На сервер переносятся только архив и контрольная сумма; локальные `.env` и `compose.demo.yml` переносить не нужно.

## Копирование и установка

Из корня проекта в PowerShell, заменив `user@server` своим SSH-адресом:

```powershell
scp dist/xtime-v1.5.0.tar.gz dist/xtime-v1.5.0.tar.gz.sha256 user@server:/tmp/
ssh user@server
```

На сервере:

```bash
cd /tmp
sha256sum -c xtime-v1.5.0.tar.gz.sha256 &&
sudo /opt/xtime/backup.sh &&
tar -xzf xtime-v1.5.0.tar.gz &&
sudo ./xtime-v1.5.0/install.sh /opt/xtime
```

Установка продолжится только после успешной проверки архива и резервного копирования. Если в рабочем `.env` задан `XTIME_TAG` с конкретной старой версией, перед установкой измените его на `v1.5.0`; пустое значение или `current` менять не требуется.

При обновлении с v1.4.1 новых миграций нет. Ожидаемая ревизия БД — **`a3b6c7d8e9f0`**. Переразбор сообщений не требуется. При обновлении с более ранней версии недостающие миграции применятся автоматически по порядку.

База остаётся в прежнем Docker-томе `pgdata` проекта `xtime`; данные никуда не переносятся. Рабочий `.env` и настройки SSH-туннеля сохраняются. Сохраните предыдущий архив и резервную копию до проверки обновления.

## Проверка после установки

```bash
cd /opt/xtime
sudo docker compose ps
sudo docker compose exec -T api python -c 'import teamtime; print(teamtime.__version__)'
sudo docker compose exec -T api alembic current
sudo docker compose logs --tail=80 api bot
```

Ожидаемые значения: версия **`v1.5.0`**, миграция **`a3b6c7d8e9f0`**. API, сайт и база — healthy; бот — запущен при настроенном подключении к Telegram. Обновите вкладку сайта через Ctrl+F5.

1. Откройте **Сегодня → Экран ТВ**. Адрес заканчивается на `/tv`, заголовок вкладки — **`xTime · Команда сегодня`**.
2. Проверьте часы с секундами, состав команды, интервалы и ближайшие изменения. На ТВ-экране нет бокового меню и кнопок.
3. На большом списке сотрудников дождитесь смены страницы через 15 секунд. Итоги сверху всегда относятся ко всей команде.

## Подключение к существующей трансляции

Установка приложения сама не меняет вкладки Firefox и настройки их переключателя. На сервере с браузером откройте адрес **`http://127.0.0.1:<порт-xTime>/tv`**. При управлении по SSH и существующей X11-сессии `:0`:

```bash
DISPLAY=:0 /usr/bin/firefox --new-tab 'http://127.0.0.1:<порт-xTime>/tv'
```

Замените `<порт-xTime>` действующим портом сайта. Если используется ранее настроенный `xtime-tv-rotation`:

- В `~/.local/bin/xtime-tv-rotation.py` у записи xTime в `SITES` замените URL на адрес с `/tv`, а `title` — на точное **`xTime · Команда сегодня`**. Общий префикс `xTime` может выбрать старую вкладку обычного дэшборда.
- В `~/.config/autostart/dashboard-browser.desktop` также обновите URL xTime в строке `Exec`, чтобы новый экран открывался после входа в графическую сессию.
- Перед правкой сохраните копии обоих файлов. После завершения текущей проверки стабильности трансляции примените настройку командой `systemctl --user restart xtime-tv-rotation`.

Эта настройка выполняется отдельно от установки релиза. Параметры Sunshine/Moonlight и битрейт обновление не меняет.

## Проверки перед выпуском

Пройдены **56 тестов фронтенда**, **36 браузерных сценариев**, линтер, проверка типов и контраста тем. В браузере проверены все состояния команды, переполнение списка, сбой и восстановление API, смена даты, секундный ход часов и сохранённая тема. Скриншоты обновлены; ТВ-экран снят в светлой и тёмной темах при 1920×1080 и 1280×720.

Код бэкенда и миграции совпадают с v1.4.1; полный набор тестов бэкенда для этого обновления повторно не запускался. При проверке релизного архива проверяются запуск собранных образов без Telegram-бота, версия приложения, ревизия БД и доступность ТВ-экрана.
