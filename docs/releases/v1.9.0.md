# xTime v1.9.0

## Что изменилось после v1.8.1

В профиле каждого сотрудника появилась кнопка **Калькулятор эффективности**.
Калькулятор оформлен в стиле приложения, поддерживает телефон и обе темы.

- **Эффективность дня** считает рабочие интервалы, обед и другие перерывы внутри
  них. Промежутки между интервалами уже исключены. Можно подставить сегодняшние
  интервалы из расписания или дейлика, указать ночное продолжение и скопировать
  готовые интервалы с процентом для сообщения.
- Рядом показаны точный процент и целый процент, который принимает дейлик.
  Например, `10:20–18:00 + 19:50–23:40` с часовым обедом дают 11:30 фактического
  времени, 10:30 эффективного и 91,30%. В дейлик копируется **91%**;
  после округления таблица учтёт **10:27:54**.
- **Доход за месяц → Цель по сумме** показывает, сколько ещё нужно фактических
  и эффективных часов до желаемого начисления. Ставка, нормы, проектные премии,
  готовое штрафное время и уже учтённые часы загружаются из обычных финансов
  за выбранный месяц. Выбранная эффективность применяется только к будущей работе.
  Дополнительное время округляется вверх до минуты; его можно распределить
  на указанное число оставшихся рабочих дней.
- **Расчёт по часам** позволяет задать фактические часы и эффективность либо
  эффективные часы напрямую. Результат показывает оклад, переработку, проектные
  премии и общую сумму. Условия можно менять для прикидки.
- Введённый сценарий сохраняется при переключении режимов и ошибке фонового
  обновления. Если финансовые данные не загрузились, доступны повтор запроса
  и явный переход к ручному вводу.
- Копирование внутри модального окна работает и при доступе по HTTP в локальной
  сети. Обновлены инструкция и скриншоты приложения.

Все сценарии выполняются в браузере. Сообщения, условия сотрудника и начисления
в базе остаются без изменений. Формула обычных финансов прежняя: полный оклад
за норму, переработка по той же ставке и проектные премии. Штрафное время влияет
на переработку. Будущие опоздания автоматически не прогнозируются.

## Обновление

Скопируйте архив `xtime-v1.9.0.tar.gz` и файл `.sha256` на сервер. Если xTime
установлен в `/opt/xtime`, в каталоге с архивом выполните:

```bash
sha256sum -c xtime-v1.9.0.tar.gz.sha256 &&
sudo /opt/xtime/backup.sh &&
tar -xzf xtime-v1.9.0.tar.gz &&
sudo ./xtime-v1.9.0/install.sh /opt/xtime
```

Установщик использует тег из пакета и сохраняет существующие настройки и базу.
После успешной проверки API он обновит маркер версии. Предыдущий архив и
резервную копию сохраните до проверки результата.

## Проверка после установки

```bash
cd /opt/xtime
sudo docker compose ps
sudo docker compose exec -T api teamtime version
sudo docker compose exec -T api alembic current
```

Ожидаются **v1.9.0** и ревизия **b0c3d4e5f6a7**. API, web и db — healthy;
bot — running, если проверка Telegram при установке прошла.

1. Обновить страницу браузера (`Ctrl+Shift+R`). Открыть **Люди → сотрудник →
   Калькулятор эффективности**.
2. На вкладке дня нажать **Пример**: результат — 11:30 фактически, 10:30
   эффективно и 91% для дейлика. Проверить копирование текста.
3. Открыть **Доход за месяц**, выбрать месяц и сверить загруженные условия
   и сумму **Сейчас в финансах** с разделом финансов.
4. Ввести желаемую сумму и эффективность, затем проверить **Расчёт по часам**.
   Закрыть калькулятор и убедиться, что исходные данные профиля и финансов сохранились.

## Проверки разработки

Пройдены 130 юнит-тестов фронтенда, TypeScript, ESLint, проверка контраста и
сборка. Полный прогон браузерных проверок: 62 сценария прошли, пять сценариев
отключённого фонда пропущены. В том числе проверены восемь сценариев калькулятора.
Полный прогон скриншотов завершился: 15 проверок прошли, одна проверка отключённого
фонда пропущена. Ночные интервалы для копирования дополнительно проверены
настоящим парсером дейликов.
