# xTime v1.9.1

## Исправление после v1.9.0

В калькуляторе эффективности убран встроенный выбор времени браузера, который
при некоторых региональных настройках показывал AM/PM и мешал вводить вечерние часы.
Теперь время всегда вводится в 24-часовом формате **00:00–23:59**.

- Можно ввести `19:50` напрямую или набрать `1950`: при выходе из поля получится
  `19:50`. Короткая запись `930` превращается в `09:30`, а `9` — в `09:00`.
- На телефоне открывается цифровая клавиатура; двоеточие вводить необязательно.
- Неверное время вроде `25:00`, `12:70` или `11:30 PM` остаётся ошибкой и не
  превращается молча в другое время. При ошибке текст для дейлика не копируется.
- Отметка окончания на следующий день берётся из рассчитанного интервала.
  Обновлены инструкция и скриншоты калькулятора.

Формулы эффективности и дохода, поведение бота и финансовые данные не меняются.
Новых миграций нет: ревизия БД **b0c3d4e5f6a7**, версия парсера **5**.
Переразбирать сообщения не требуется. Фонд остаётся отключённым.

## Обновление

Скопируйте архив `xtime-v1.9.1.tar.gz` и файл `.sha256` на сервер. В каталоге
с архивом выполните:

```bash
sha256sum -c xtime-v1.9.1.tar.gz.sha256 &&
sudo /opt/xtime/backup.sh &&
tar -xzf xtime-v1.9.1.tar.gz &&
sudo ./xtime-v1.9.1/install.sh /opt/xtime
```

Настройки и база сохраняются. После установки:

```bash
cd /opt/xtime
sudo docker compose ps
sudo docker compose exec -T api teamtime version
```

Ожидается **v1.9.1**. Обновите страницу через **Ctrl+Shift+R** и откройте
**Люди → сотрудник → Калькулятор эффективности**. Время должно вводиться как
`19:50–23:40` без переключателя AM/PM, в том числе в браузере с английской локалью.

## Проверки исправления

Пройдены десять браузерных сценариев калькулятора: восемь прежних и две регрессии
с локалью `en-US` на компьютере и телефоне. Проверены короткая запись, вечерние
часы, ошибки ввода, копирование и отсутствие горизонтальной прокрутки.
TypeScript, ESLint и сборка прошли. Восемь скриншотов калькулятора обновлены
для компьютера и телефона в обеих темах.
