# xTime v1.2.0

## Изменения

- «Сегодня» показывает всю команду: кто работает в офисе или удалённо, начнёт позже, закончил, отдыхает, отсутствует или не указал расписание.
- Дейлики и опоздания перенесены во вложенные «Итоги дня» с выбором даты. Часы подписаны городом и UTC-смещением.
- Нажатие на сотрудника показывает задачи, кнопка «Подробнее» открывает день. Длинные списки раскрываются с внутренней прокруткой.
- В профиле сотрудника появились фото, телефон, Telegram, описание, расписание и задачи недели. Контакты заполняет админ.
- Кнопки «Факты недели» и «Факты месяца» показывают события по дейликам с переходом к исходному дню.
- В инбоксе видно, что изменилось в расписании и как одобрение повлияет на опоздание. Действие требует подтверждения.
- Бот напоминает в личке через 15 минут после конца смены, если дейлика нет. Напоминания защищены от повторов при перезапусках, параллельных процессах, таймаутах и сбоях БД.
- Ответы бота оформлены блоками с выделенными показателями и кнопками. Большие отчёты делятся на сообщения.
- Во всех текстах используется слово «таблица». Исправлен запуск контейнера из рабочей копии Windows.

## Файлы обновления

- `xtime-v1.2.0.tar.gz` — автономный архив для Linux amd64: образы API/бота, сайта и PostgreSQL, установщик и инструкция.
- `xtime-v1.2.0.tar.gz.sha256` — контрольная сумма архива.
- Внутри архива: `VERSION`, `UPDATE.md`, `README.md`, `images.tar.gz`, `docker-compose.yml`, `.env.example`, `install.sh`, `backup.sh` и сервис SSH-туннеля.

## Как обновить существующий сервер

В командах ниже замените `user@server` на свой SSH-адрес. С компьютера разработчика:

```powershell
scp dist/xtime-v1.2.0.tar.gz dist/xtime-v1.2.0.tar.gz.sha256 user@server:/tmp/
ssh user@server
```

На сервере:

```bash
cd /tmp
sha256sum -c xtime-v1.2.0.tar.gz.sha256
sudo /opt/xtime/backup.sh
tar -xzf xtime-v1.2.0.tar.gz
sudo ./xtime-v1.2.0/install.sh /opt/xtime
cd /opt/xtime
sudo docker compose ps
sudo docker compose exec -T api python -c 'import teamtime; print(teamtime.__version__)'
sudo docker compose exec -T api alembic current
sudo docker compose logs --tail=50 api bot
```

Ожидаемая версия — `v1.2.0`, миграция — `e1f4a5b6c7d8`.
Откройте сайт по обычному адресу и проверьте «Сегодня», профиль сотрудника и инбокс.
Рабочий `.env` остаётся на сервере; локальный демо-файл загружать не нужно.
Миграции применяются автоматически, база и настройки сохраняются. SSH-туннель Telegram продолжает использовать существующую конфигурацию.
Старые образы оставьте до завершения проверки обновления.

## Напоминания

В «Админка → Настройки → Бот» проверьте включение напоминаний и задержку 15 минут.
Ранее сохранённое отключение остаётся в силе. Для личных уведомлений аккаунт должен
быть привязан к сотруднику, а сотрудник — хотя бы один раз написать боту `/start`.
Без личного диалога Telegram не разрешит боту первым написать человеку.

Проверка идёт раз в минуту по последнему рабочему интервалу с учётом ночной смены.
Пришедший дейлик, отменённая смена, праздник или неактивный сотрудник исключают напоминание.
Попытка сохраняется до отправки: при неизвестном результате повтор не выполняется,
поэтому в аварийном случае напоминание может быть пропущено. Явный отказ 429 повторяется
с паузой, максимум три попытки. Просроченные более чем на час напоминания не догоняются.
