# xTime v1.7.1

## Исправления после v1.7.0

- На ТВ-экране колонка сотрудника ограничена шириной 205–240 px вместо 28% карточки.
  Убрано лишнее пустое место после фамилии, освобождённая ширина отдана шкале времени.
  Подписи часов и общая линия текущего времени выравниваются по новой шкале.
- Интервалы офисного расписания теперь имеют насыщенную зелёную заливку, удалённого —
  синюю. Используются цвета текущей темы; контраст относительно дорожки превышает 4:1
  в светлой и тёмной темах. Цвет отражает место работы по расписанию.
- Проверены 20 сотрудников в Full HD, отображение в HD, длинная фамилия, несколько
  интервалов и обе темы. На небольших экранах сохраняется автоматическая смена страниц.

Новых миграций после v1.7.0 нет. Правила расчёта, отделы и данные сотрудников не меняются.

## Обновление сервера

Архив для **Linux amd64** и контрольная сумма находятся в `D:\xTimeReleases\v1.7.1`.
В PowerShell замените SSH-адрес своим:

```powershell
$xtimeServer = "user@server"
scp D:/xTimeReleases/v1.7.1/xtime-v1.7.1.tar.gz D:/xTimeReleases/v1.7.1/xtime-v1.7.1.tar.gz.sha256 "${xtimeServer}:/tmp/"
ssh $xtimeServer
```

На сервере с установкой в `/opt/xtime`:

```bash
cd /tmp &&
sha256sum -c xtime-v1.7.1.tar.gz.sha256 &&
sudo /opt/xtime/backup.sh &&
sudo cp -p /opt/xtime/.env /opt/xtime/backups/env-before-v1.7.1 &&
tar -xzf xtime-v1.7.1.tar.gz &&
sudo sed -i 's/^XTIME_TAG=.*/XTIME_TAG=v1.7.1/' /opt/xtime/.env &&
sudo ./xtime-v1.7.1/install.sh /opt/xtime
```

При отсутствии `XTIME_TAG` используются загруженные образы `current`.
Рабочий `.env`, база и контексты агентов в архив не входят.

## Проверка

```bash
cd /opt/xtime
sudo docker compose ps
sudo docker compose exec -T api python -c 'import teamtime; from teamtime.parsing import PARSER_VERSION; print(teamtime.__version__, PARSER_VERSION)'
sudo docker compose exec -T api alembic current
```

Ожидается **`v1.7.1 4`**, ревизия **`c5d8e9f0a1b2`**. API, сайт и база — healthy.

На компьютере трансляции выберите вкладку xTime в Firefox и нажмите **Ctrl+Shift+R**.
Настройки Sunshine/Moonlight и чередование вкладок сохраняются. Проверьте уменьшенный
отступ после фамилии, цветные интервалы и положение красной линии текущего времени.

Для отката сохраните архив v1.7.0 и резервную копию до обновления. При обновлении с
более ранних версий действуют инструкции и особенности миграций соответствующих выпусков.
