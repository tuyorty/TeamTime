# xTime v1.7.0

## Что изменилось после v1.6.0

- Добавлены отделы **Программисты** и **Лаборатория**. Программисты идут первыми, внутри
  каждого отдела сотрудники расположены по алфавиту. На общих экранах появились заголовки
  групп; две группы из 20 человек помещаются в Full HD на одной странице ТВ.
- Фильтр **Отдел** доступен в «Сегодня», итогах дня, неделе, месяце, планах, финансах,
  людях, календаре и справочнике сотрудников. Экспорт текущего отбора использует выбранных
  людей. Общие графики недели и истории месяца относятся ко всей команде; фильтр меняет
  состав таблицы. Финансовые суммы и графики учитывают отбор.
- В **Админка → Telegram → Чаты** можно назначить отдел сотрудникам из конкретной беседы.
  Существующие сотрудники определяются по обработанным сообщениям, включая импорт.
  При первом распознавании новых людей используется отдел чата. Отдел отдельного
  сотрудника редактируется в его карточке; последующие сообщения его не перезаписывают.
- В списке Telegram-аккаунтов добавлено удаление неизвестных непривязанных записей.
  Повторный импорт не возвращает их; исходные сообщения и история сотрудников сохраняются.
  Есть список удалённых и восстановление. Привязанный аккаунт сначала нужно отвязать.
- В инбоксе появилась **Массовая обработка дейликов** с отбором по беседе, сотруднику,
  периоду и источнику. До применения видны количество и примеры всех подходящих записей,
  включая другие страницы. Можно подтвердить дейлики без эффективности, оставив её
  неизвестной, или закрыть старые сообщения без времени без начисления часов.
  Значения 100%, рабочие интервалы и даты автоматически не подставляются.
- В профиле сотрудника появились стрелки месяцев, выбор месяца и кнопка **Текущий**.
  Итоги прошлого месяца, норма и ставка соответствуют выбранному месяцу и истории условий.
  Сохраняются выбор нескольких месяцев и произвольного периода.

Правила отпуска и командировок из v1.6.0 сохраняются. Миграция не меняет часы и эффективность,
не удаляет Telegram-аккаунты и не закрывает вопросы без действия администратора.

## Первоначальная настройка после обновления

1. В **Админка → Telegram → Чаты** у лабораторной беседы выберите **Лаборатория** и нажмите
   **Применить отдел**. Все ранее созданные сотрудники при миграции относятся к программистам;
   назначение отдела чату переносит определённых по его сообщениям людей в лабораторию.
   Если человек ещё не определён, сначала добавьте сотрудника и привяжите Telegram-аккаунт.
2. Проверьте состав в **Люди**, при необходимости исправьте отдел отдельных сотрудников.
3. Ненужные аккаунты убирайте корзиной в **Админка → Telegram**. Не удаляйте сотрудников,
   когда нужно убрать только неизвестную запись Telegram.
4. В **Инбокс → Ждут решения → Массовая обработка дейликов** выберите лабораторную беседу
   и нужный период. Сначала проверьте предпросмотр для дейликов без эффективности, затем
   отдельно — для сообщений без времени. Подтверждение не начисляет дополнительные часы.

Подробности находятся в `MULTIPLE_CHATS.md` и `LEGACY_IMPORT.md` внутри архива.

## Файлы

- `xtime-v1.7.0.tar.gz` — автономный архив для **Linux amd64** с образами приложения и PostgreSQL.
- `xtime-v1.7.0.tar.gz.sha256` — контрольная сумма.
- Рабочий `.env`, данные сотрудников и контексты агентов в архив не входят.

## Обновление существующего сервера

Скопируйте архив и контрольную сумму на сервер, заменив SSH-адрес в PowerShell:

```powershell
$xtimeServer = "user@server"
scp D:/xTimeReleases/v1.7.0/xtime-v1.7.0.tar.gz D:/xTimeReleases/v1.7.0/xtime-v1.7.0.tar.gz.sha256 "${xtimeServer}:/tmp/"
ssh $xtimeServer
```

На сервере с установкой в `/opt/xtime`:

```bash
cd /tmp &&
sha256sum -c xtime-v1.7.0.tar.gz.sha256 &&
sudo /opt/xtime/backup.sh &&
sudo cp -p /opt/xtime/.env /opt/xtime/backups/env-before-v1.7.0 &&
tar -xzf xtime-v1.7.0.tar.gz &&
sudo sed -i 's/^XTIME_TAG=.*/XTIME_TAG=v1.7.0/' /opt/xtime/.env &&
sudo ./xtime-v1.7.0/install.sh /opt/xtime
```

Если `XTIME_TAG` отсутствует, установщик использует загруженные образы `current`.
Миграции применяются автоматически; ожидаемая ревизия — **`c5d8e9f0a1b2`**.
Существующие тома базы, настройки и туннель Telegram сохраняются.

```bash
cd /opt/xtime
sudo docker compose ps
sudo docker compose exec -T api python -c 'import teamtime; from teamtime.parsing import PARSER_VERSION; print(teamtime.__version__, PARSER_VERSION)'
sudo docker compose exec -T api alembic current
sudo docker compose logs --tail=80 api bot
```

Ожидается **`v1.7.0 4`**, ревизия **`c5d8e9f0a1b2`**. API, сайт и база — healthy.
После установки обновите вкладки браузера через Ctrl+Shift+R, включая Firefox, который
транслируется на телевизор через Moonlight. Настройка чередования вкладок сохраняется.

## Откат

Сохраните предыдущий архив и резервную копию до проверки обновления. При полном откате
восстановите копию базы до обновления и прежние образы по `README.md`. Откат миграции
v1.7.0 удаляет настройки отделов и отметки удалённых аккаунтов; не выполняйте его отдельно
от согласованного восстановления приложения и данных. Новые ручные решения инбокса
хранятся в базе и журнале правок.
