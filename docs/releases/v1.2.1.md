# xTime v1.2.1

## Изменения после v1.2.0

- Убрал из бота все кнопки и ссылки на локальный дэшборд: профиль, расписание, статистику и итоги дня. Отчёты доступны прямо в Telegram; переход к итогам дня работает действием бота.
- Полный список недельных задач теперь приходит в Telegram без отсылки на сайт. Большие отчёты делятся на сообщения с сохранением HTML-разметки.
- В напоминаниях оставил переход к теме «Дейлики» и проверку сообщений внутри бота. Правила отправки и защита от повторов не изменились.
- Добавил настройку фотографии сотрудника: перемещение мышью, пальцем или стрелками, масштаб 100–400%, круглый предпросмотр и сброс кадра.
- Выбранный квадрат сохраняется вместе с профилем в размере 256 × 256. Сохранённое фото можно дополнительно настроить; для выбора области за пределами прежнего кадра нужно загрузить исходный снимок заново.
- Исправил горизонтальный выход админки за границы экрана на телефоне.

Проверки: 435 тестов бэкенда, 42 теста фронтенда, 16 браузерных сценариев.
Скриншоты светлой и тёмной тем, компьютера и телефона обновлены.

## Файлы обновления

- `xtime-v1.2.1.tar.gz` — автономный архив с образами приложения и PostgreSQL для Linux amd64.
- `xtime-v1.2.1.tar.gz.sha256` — контрольная сумма архива.
- Внутри архива есть установщик, `VERSION`, `README.md` и эта инструкция под именем `UPDATE.md`.

## Копирование на сервер

Из корня проекта в PowerShell, заменив `user@server` своим SSH-адресом:

```powershell
scp dist/xtime-v1.2.1.tar.gz dist/xtime-v1.2.1.tar.gz.sha256 user@server:/tmp/
ssh user@server
```

## Установка

На сервере:

```bash
cd /tmp
sha256sum -c xtime-v1.2.1.tar.gz.sha256 &&
sudo /opt/xtime/backup.sh &&
tar -xzf xtime-v1.2.1.tar.gz &&
sudo ./xtime-v1.2.1/install.sh /opt/xtime
```

Рабочий `.env`, база, настройки и SSH-туннель остаются на месте.
Локальный демо-файл `.env` переносить не нужно.
Новых миграций после v1.2.0 нет; текущая ревизия остаётся `e1f4a5b6c7d8`.
Установщик применит ранее не установленные миграции автоматически.

## Проверка после установки

Команды Compose выполняйте из `/opt/xtime`, где находится конфигурация:

```bash
cd /opt/xtime
sudo docker compose ps
sudo docker compose exec -T api python -c 'import teamtime; print(teamtime.__version__)'
sudo docker compose exec -T api alembic current
sudo docker compose logs --tail=50 api bot
```

Ожидаемая версия — `v1.2.1`. API, сайт и база должны быть healthy, бот — работать.
Откройте профиль сотрудника в режиме админа, загрузите фото, выберите кадр и сохраните.
Проверьте свежие ответы `/week`, `/me` и `/today`: кнопок локального сайта в них быть не должно.
Ранее отправленные сообщения Telegram сохраняют прежний вид.

Образы `v1.2.0` оставьте до завершения проверки обновления. Теги `current` и `v1.2.1`
с одинаковым IMAGE ID обозначают один образ и не занимают место дважды.
