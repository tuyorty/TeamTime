# xTime v1.8.1

## Исправление экрана телевизора

После v1.8.0 экран `/tv` мог останавливаться с ошибкой
`Cannot read properties of undefined (reading 'includes')`.
Компоненты шкалы ожидали полную ячейку дня, а API телевизора отдаёт только
расписание, без фактов, штрафов и источников сообщений.

Теперь интерфейс использует отдельный тип ограниченного ответа и заполняет
недостающие поля при подготовке полосы расписания. Ограничения доступа
телевизора сохраняются. Добавлена браузерная проверка настоящего API без
подмены данных; тестовые ответы и скриншоты приведены к тому же контракту.

## Обновление после v1.8.0

Новых миграций и изменений парсера нет. Ревизия БД остаётся
`b0c3d4e5f6a7`, версия парсера — **5**. Переразбирать сообщения не требуется.

Скопируйте архив и файл `.sha256` на сервер. В каталоге с архивом:

```bash
sha256sum -c xtime-v1.8.1.tar.gz.sha256 &&
sudo /opt/xtime/backup.sh &&
tar -xzf xtime-v1.8.1.tar.gz &&
sudo ./xtime-v1.8.1/install.sh /opt/xtime
```

После установки откройте `/tv` и обновите страницу с очисткой кэша
(`Ctrl+Shift+R` в Firefox). Проверьте строки сотрудников, полосы рабочих
интервалов и заголовок вкладки **xTime · Команда сегодня**.
При отдельном переключателе офисных сервисов проверьте также привязку
вкладок: страница восстановления Firefox или лишние вкладки могут изменить
их позиции независимо от версии xTime.
