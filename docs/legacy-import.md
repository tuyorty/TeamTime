# Старые дейлики и посторонние Telegram-аккаунты

## Массовая обработка

Откройте **Инбокс → Ждут решения → Массовая обработка дейликов** в режиме администратора.
Выберите сотрудника, беседу и даты сообщений. По умолчанию обрабатываются только сообщения
из импорта; переключатель позволяет включить сообщения из бота и демо.

Есть два отдельных действия:

- **Только нет эффективности — подтвердить как есть.** Подходят дейлики с датой, временем
  и определённым сотрудником, у которых единственное предупреждение — отсутствие
  эффективности. Эффективность остаётся неизвестной, исходные часы сохраняются, зачтённый
  результат не подменяется нулём или 100%. Дейлик остаётся в статистике как день без
  эффективности. Записи с другими ошибками или предупреждениями остаются для проверки.
- **Нет времени работы — закрыть без начисления часов.** Подходят неразобранные дейлики
  без интервалов времени, включая старые записи «Без науки» и текст за несколько дат.
  Они переводятся в «Решённые» с решением «не учитывается». Часы, дату или эффективность
  система не придумывает. Текст сообщения и история разборов сохраняются.

Нажмите **Предпросмотр выборки**: появятся количество и примеры. Выборка охватывает все
страницы инбокса, а не только видимые 25 сообщений. Затем подтвердите количество записей.
За один раз доступно до 5000 записей; для большей истории уточните период или сотрудника.
Если после предпросмотра кто-то уже обработал запись, операция не применяется частично:
нужно обновить предпросмотр. Все решения записываются в журнал правок.

Подтверждение не меняет исходные сообщения, эффективность, рабочие часы и расчёт оплаты.
При последующем редактировании исходного сообщения или явном переразборе может появиться
новый вопрос: это новая версия данных, которую следует проверить.

## Удаление неизвестных аккаунтов

В **Админка → Telegram → Аккаунты Telegram** у непривязанной записи нажмите значок корзины.
Подтверждение убирает аккаунт из действующего списка, закрывает его вопросы без определённого
сотрудника и отключает обработку новых сообщений этого автора. Повторный импорт его не
восстановит. Уже сохранённые исходные сообщения и данные сотрудников не удаляются.

Аккаунт с действующей привязкой к сотруднику удалить нельзя: сначала проверьте, кому он
принадлежит, и при необходимости снимите привязку. Это отдельное действие от удаления
сотрудника, которое затрагивает его планы и дейлики.

Для отмены откройте **Удалённые аккаунты → Восстановить аккаунт**. После восстановления
можно вновь привязать человека; прежние закрытые сообщения доступны в «Инбокс → Решённые».
