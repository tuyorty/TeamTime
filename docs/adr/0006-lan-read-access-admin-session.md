# ADR 0006. Чтение без входа, админ по паролю из .env

- Статус: принято
- Дата: 2026-10-26

## Контекст

Сайт работает в локальной сети команды. Сейчас все видят общую Google-таблицу целиком, включая ставки и премии. Правки должен делать только админ.

## Решение

- Все `GET` открыты без авторизации.
- `POST /api/v1/auth/login` сверяет пароль с `ADMIN_PASSWORD` (через `hmac.compare_digest`) и ставит подписанную cookie (`itsdangerous`, `HttpOnly`, `SameSite=Strict`, срок задаётся настройкой).
- Изменяющие запросы требуют сессию и заголовок `X-Requested-With`, это простая CSRF-защита вместе с `SameSite`.
- После пяти неверных паролей с одного адреса вход блокируется на минуту.
- Любая правка пишет `AuditLog` с актором `admin` и необязательной причиной.

## Последствия

- Это не защита от злоумышленника внутри сети, и README говорит об этом прямо. Для доступа извне используется бот, а не проброс порта.
- Пустой `ADMIN_PASSWORD` выключает режим админа. Демо-режим задаёт пароль `demo` и пишет его на странице входа.
