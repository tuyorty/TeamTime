# ADR 0001. Монорепозиторий и один Python-пакет для API и бота

- Статус: принято
- Дата: 2026-10-26

## Контекст

У бота и API одно доменное ядро: разбор сообщений, версии планов и дейликов, расчёты, аудит. Если сделать их отдельными пакетами, общий код пришлось бы выносить в третий пакет и синхронизировать версии.

## Решение

Один пакет `teamtime` в `backend/`. Бот — подпакет `teamtime.bot`. Оба процесса собираются из одного Docker-образа и запускаются разными командами (`uvicorn teamtime.api.app:app` и `teamtime bot run`). Фронтенд лежит рядом, в `frontend/`.

## Последствия

- Изменение парсера сразу видят и бот, и импорт, и API. Расходиться им не из-за чего.
- Образ бота несёт зависимости FastAPI, лишние ему. Для команды из десятка человек это приемлемо.
- Границы внутри пакета держатся на соглашении: `parsing` и `calc` не импортируют `db`. Это проверяет тест `tests/test_architecture.py`.
