# ADR 0005. Точная арифметика времени и усечение при показе

- Статус: принято
- Дата: 2026-10-26

## Контекст

`Итог = Часы × e%` даёт доли минуты (6:43 × 60% = 4:01:48), а штрафная шкала даёт доли секунды. Исходная таблица показывает время в формате `ч:мм`, отбрасывая остаток. Чтобы наши числа совпадали с ней, нужна одинаковая политика округления. Ошибки float (7:36 → 7:35,999… → 7:35) недопустимы.

## Решение

- Внутри `calc` длительности хранятся как `fractions.Fraction` секунд. Время суток — целые секунды от полуночи.
- Суммы за месяц складываются точно. Усечение происходит только при показе: до минут в UI, до целых секунд в API (поле `*_seconds`).
- Деньги считаются в `Decimal` и округляются до копеек по `ROUND_HALF_UP`.
- В UI рядом с итогами подпись «значения усечены до минут».

## Последствия

- Золотые тесты сравнивают строки `ч:мм` и точные дроби, поэтому расхождение в одну минуту ловится сразу.
- API отдаёт целые секунды. Фронтенд не пересчитывает итоги, он только форматирует.
